Part A · Getting Started

1 · About This App & What's New

The TeamTalk VoiceOver Client is a graphical client for the TeamTalk protocol, built specifically for blind and visually impaired users. All controls are optimized for screen readers:

  • macOS – VoiceOver with braille display support (primary platform)
  • Windows – NVDA, JAWS (fully supported, Alt+letter shortcuts for all buttons)
  • Linux – Orca (basic support)

TeamTalk is a voice communication service similar to Mumble or Discord. The client connects to a TeamTalk server, joins channels, and enables voice and text communication.

The app supports four interface languages: German, English, French, Spanish. The language can be changed under Settings → General → App Language; the app then restarts.

3 · Installation & First Launch

macOS

  1. Open the DMG file (double-click).
  2. Drag "TeamTalk VO Client.app" into the Applications folder.
  3. On first launch: right-click → "Open" (one-time, due to the Gatekeeper warning).
  4. Grant microphone and, if needed, screen recording permission when prompted.

Windows

  1. Download the EXE or ZIP file.
  2. Extract the ZIP contents into a folder (e.g. C:\Program Files\TeamTalk VO Client).
  3. Start TeamTalk VO Client.exe.
  4. Windows Defender / SmartScreen: choose "Run anyway".

Linux

  1. Download and extract the AppImage or tar.gz.
  2. Make the AppImage executable: chmod +x TeamTalk*.AppImage
  3. Launch: ./TeamTalk*.AppImage
  4. Install espeak-ng if not already present: sudo apt install espeak-ng

First Launch

On first launch, the main window opens. To connect, first open the connection window via File → Connect or the Connect button in the quick actions bar. Server connections are saved as profiles and restored on every launch.

App Update

Via Help → Check for Updates, the app checks whether a new version is available. The update DMG (macOS) is downloaded and saved directly within the app – no browser access to the repository required.

9 · Channels, User List & Chat

This is the main "Channels and Chat" area. It is divided into two halves:

Left Half: Channels & Users

  • Channel list: Shows all channels on the server. Format: Channel name, Users: N, Password: Yes/No. Double-click or Enter joins the channel. Channel passwords are requested when needed.
  • User list: Shows all users in the current channel. Format: Nickname, Username, Status. Double-click opens a private chat with that user.

The Join channel button (Alt+K) joins the selected channel.

Right Half: Chat

  • Chat history: Multi-line text field with channel and private messages.
  • Input field: Type a message, then press Enter or "Send" (Alt+S).
  • Private checkbox (Alt+P): Send the message as a private message to the selected user.
  • Export history (Alt+E): Saves the chat history as a TXT file.
  • Clear history (Alt+L): Deletes the displayed history after confirmation. If history saving is enabled, the saved file is also deleted.

Saving Chat History (optional)

When enabled under Settings → General → Save chat history, messages are saved per server in a JSON file (max. 200 entries). The history is automatically loaded the next time you connect to the same server.

The history can be reset at any time via "Clear history".

10 · Notifications

macOS – Native Notifications

macOS system notifications for channel events appear only when the affected user is in the same channel as you. This reduces irrelevant notifications on crowded servers.

Notifications can be turned on and off centrally via Settings → Display → Enable Notifications.

EventNotification (example)
User joins your channel"Florian has joined – channel Lounge"
User leaves your channel"Florian has left – channel Lounge"
New private messageSender name + message preview
To disable notifications: turn off Settings → Display → Enable Notifications. Alternatively, you can disable them globally in System Settings → Notifications → TeamTalk VO Client.

Sound Events

In addition to native notifications, a custom sound can be played for each event. Configuration is done under Settings → Sound Events (→ Section 18).

Notification Rules NEW as of v7.1

Via Settings → Notification Rules…, you finely control which events trigger TTS, a sound, both, or nothing. Rules apply from specific to general: a user rule beats a channel rule, which beats a server rule, which beats a global rule.

Fields of a Rule

FieldDescription
EventWhich event this rule affects: all, user joins/leaves channel, channel chat, private message, etc.
Keyword NEW v7.4Optional: the rule only applies if the message contains this word (case-insensitive). Only active for message events.
ScopeGlobal, server, channel, or user
ValueName of the server / channel / user (leave empty for Global)
ActionTTS + sound, TTS only, sound only, or mute (suppress everything)

Examples

  • Suppress all chat messages except in the "Lounge" channel: global rule "Chat → Mute", then a more specific rule "Chat, channel: Lounge → TTS + sound".
  • TTS only when the keyword "important" appears: rule "Chat, keyword: important → TTS". No TTS is triggered without the keyword in the message.
  • Always read out private messages from user "Max": rule "Private message, user: Max → TTS + sound".

Order and Priority

Rules are searched from top to bottom. The first matching rule wins. More specific rules (user before channel before server before global) should therefore be placed higher up. Use "Move up"/"Move down" to adjust the order.

  4. Click Stream (Alt+R).

  1. Choose a station from the predefined list, or search for stations (Alt+S).
  2. The stream URL can also be entered manually.
  3. Click Stream Web Radio (Alt+W).

Podcasts

  1. Search for a podcast name (Alt+S) or enter the feed URL directly.
  2. Load the feed (Alt+F).
  3. Select an episode from the list and click Stream Episode (Alt+E).

Playlist

  1. Add files via Add… (Alt+H) or Load M3U… (Alt+M) to the playlist.
  2. Adjust the order with "Move up" / "Move down".
  3. Play starts from the selected track; with "Auto-advance" the playlist plays through automatically.
  4. Export the playlist as M3U or remove individual tracks.

Spotify NEW

Requires Spotify Premium and the bundled librespot binary.
  1. On first launch, click Log in with Spotify… — the browser opens automatically.
  2. Log in with your Spotify account in the browser; the page confirms success.
  3. Customize the device name as desired (default: "TeamTalk Stream").
  4. Choose the quality (320 / 160 / 96 kbps).
  5. Click Start Spotify.
  6. In the Spotify app (phone, desktop, or web), tap the speaker icon and select the device name.
  7. Control the music in the Spotify app — the audio is streamed live into the channel.

After the first login, the credentials are saved locally; no need to log in again on subsequent launches. Use Log out to delete the saved credentials.

If librespot is missing: run python scripts/download_librespot.py in the project directory (requires Rust / Cargo).

Deezer NEW

ARL token required. Deezer has disabled username/password login for third-party applications.

How to get the ARL token:

  1. Log in to deezer.com in your browser.
  2. Open developer tools (F12) → Application (Chrome) or Storage (Firefox) → Cookies → deezer.com.
  3. Copy the value of the arl cookie (192 characters).

Using the token in the client:

  1. Paste the ARL token into the "ARL Token" field and click Save Token (one-time, saved locally).
  2. Enter a search term and click Search — the public Deezer search doesn't require an account.
  3. Select a track from the results list and click Stream.
  4. The track is downloaded and automatically streamed into the channel.

The ARL token expires every 3–6 months. If you get an error, simply copy a new one from the browser.

Part H · Reference

21 · Platform Differences

macOS

  • VoiceOver navigation: VO+arrow keys move through all elements. VO+Space activates. VO+M for the menu bar.
  • Lists: Announced as "List, N items" (VoiceOver patch active). Up/down arrow keys navigate.
  • Dropdowns: Announced as "pop-up button". Arrow keys change the value.
  • Number fields (SpinCtrl): Arrow keys change the value; direct entry is possible.
  • Focus shortcuts: Cmd+1–4 set focus to the channel list, chat history, input, log.
  • Closing the window: Cmd+W minimizes to the tray. Cmd+Q quits completely.
  • Standard shortcuts: Cmd+O (open file), Cmd+N (new client), Cmd+, (settings).
  • Microphone permission: macOS asks for microphone access once. Grant it in System Settings → Privacy.
  • Braille display: All control names and roles are named in your chosen interface language.
  • Notifications: Native macOS notifications for channel events (channel-based filtering since v6.1.6).

Windows

  • NVDA/JAWS navigation: Tab/Shift+Tab navigates, Enter/Space activates. In forms mode, arrow keys navigate within lists.
  • Keyboard shortcuts: Alt+underlined letter activates buttons/checkboxes. All buttons have unique shortcuts per area.
  • Menu navigation: Alt opens the menu bar, then letters.
  • Standard shortcuts: Ctrl+O, Ctrl+N, F4 (settings).
  • Tray: Double-click the tray icon to reopen the window. Right-click opens the tray menu.
  • Windows Defender: You may need to add an exception on first launch.

Linux

  • Orca navigation: Similar to Windows. Insert+Tab for the elements list.
  • Audio devices: PulseAudio or ALSA. Choose the device name in the dropdown.
  • espeak-ng: The system version is preferred (sudo apt install espeak-ng).
  • Tray: Works with compatible desktop environments (GNOME with AppIndicator extension, KDE).
  • Limitations: Desktop sharing and mouse remote control may be limited depending on the compositor.
