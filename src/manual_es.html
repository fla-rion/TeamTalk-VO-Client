Parte A · Introducción

1 · Acerca de esta aplicación y novedades

El TeamTalk VoiceOver Client es un cliente gráfico para el protocolo TeamTalk, desarrollado especialmente para usuarios ciegos y con baja visión. Todos los controles están optimizados para lectores de pantalla:

  • macOS – VoiceOver con soporte de línea braille (plataforma principal)
  • Windows – NVDA, JAWS (totalmente compatible, atajos Alt+letra para todos los botones)
  • Linux – Orca (compatibilidad básica)

TeamTalk es un servicio de comunicación por voz similar a Mumble o Discord. El cliente se conecta a un servidor TeamTalk, se une a canales y permite la comunicación por voz y texto.

La aplicación admite cuatro idiomas de interfaz: alemán, inglés, francés, español. El idioma se puede cambiar en Configuración → General → Idioma de la aplicación; la aplicación se reiniciará después.

3 · Instalación y primer inicio

macOS

  1. Abrir el archivo DMG (doble clic).
  2. Arrastrar "TeamTalk VO Client.app" a la carpeta Aplicaciones.
  3. En el primer inicio: clic derecho → "Abrir" (una sola vez, debido a la advertencia de Gatekeeper).
  4. Conceder el permiso de micrófono y, si procede, de grabación de pantalla cuando se solicite.

Windows

  1. Descargar el archivo EXE o ZIP.
  2. Extraer el contenido del ZIP en una carpeta (p. ej. C:\Archivos de programa\TeamTalk VO Client).
  3. Iniciar TeamTalk VO Client.exe.
  4. Windows Defender / SmartScreen: elegir "Ejecutar de todas formas".

Linux

  1. Descargar y extraer el AppImage o tar.gz.
  2. Hacer ejecutable el AppImage: chmod +x TeamTalk*.AppImage
  3. Iniciar: ./TeamTalk*.AppImage
  4. Instalar espeak-ng si aún no está presente: sudo apt install espeak-ng

Primer inicio

En el primer inicio se abre la ventana principal. Para conectarse, primero abra la ventana de conexión mediante Archivo → Conectar o el botón Conectar en la barra de acciones rápidas. Las conexiones de servidor se guardan como perfiles y se restauran en cada inicio.

Actualización de la aplicación

Mediante Ayuda → Buscar actualizaciones, la aplicación comprueba si hay una versión nueva disponible. El DMG de actualización (macOS) se descarga y guarda directamente dentro de la aplicación – no se necesita acceso al repositorio mediante navegador.

9 · Canales, lista de usuarios y chat

Esta es el área principal "Canales y Chat". Se divide en dos mitades:

Mitad izquierda: canales y usuarios

  • Lista de canales: muestra todos los canales del servidor. Formato: Nombre del canal, Usuarios: N, Contraseña: Sí/No. Doble clic o Intro se une al canal. Las contraseñas de canal se solicitan cuando es necesario.
  • Lista de usuarios: muestra todos los usuarios del canal actual. Formato: Apodo, Nombre de usuario, Estado. El doble clic abre un chat privado con ese usuario.

El botón Unirse al canal (Alt+K) se une al canal seleccionado.

Mitad derecha: chat

  • Historial del chat: campo de texto de varias líneas con mensajes de canal y privados.
  • Campo de entrada: escribir un mensaje y luego pulsar Intro o "Enviar" (Alt+S).
  • Casilla Privado (Alt+P): enviar el mensaje como mensaje privado al usuario seleccionado.
  • Exportar historial (Alt+E): guarda el historial del chat como archivo TXT.
  • Borrar historial (Alt+L): elimina el historial mostrado tras confirmación. Si el guardado del historial está activo, también se elimina el archivo guardado.

Guardar el historial del chat (opcional)

Si está activado en Configuración → General → Guardar historial de chat, los mensajes se guardan por servidor en un archivo JSON (máx. 200 entradas). El historial se carga automáticamente en la próxima conexión al mismo servidor.

El historial se puede restablecer en cualquier momento mediante "Borrar historial".

10 · Notificaciones

macOS – Notificaciones nativas

Las notificaciones del sistema de macOS para eventos de canal aparecen solo cuando el usuario afectado está en el mismo canal que usted. Esto reduce las notificaciones irrelevantes en servidores concurridos.

Las notificaciones se pueden activar y desactivar de forma centralizada mediante Configuración → Visualización → Activar notificaciones.

EventoNotificación (ejemplo)
Un usuario se une a su canal"Florian se ha unido – canal Lounge"
Un usuario abandona su canal"Florian ha salido – canal Lounge"
Nuevo mensaje privadoNombre del remitente + vista previa del mensaje
Para desactivar las notificaciones: desactive Configuración → Visualización → Activar notificaciones. También puede desactivarlas de forma global en Configuración del sistema → Notificaciones → TeamTalk VO Client.

Eventos sonoros

Además de las notificaciones nativas, se puede reproducir un sonido propio para cada evento. La configuración se realiza en Configuración → Eventos sonoros (→ Sección 18).

Reglas de notificación NUEVO desde v7.1

Mediante Configuración → Reglas de notificación…, controla con detalle qué eventos activan TTS, sonido, ambos o nada. Las reglas se aplican de lo específico a lo general: una regla de usuario vence a una regla de canal, que vence a una regla de servidor, que vence a una regla global.

Campos de una regla

CampoDescripción
EventoA qué evento afecta esta regla: todos, usuario entra/sale del canal, chat de canal, mensaje privado, etc.
Palabra clave NUEVO v7.4Opcional: la regla solo se aplica si el mensaje contiene esta palabra (sin distinción de mayúsculas/minúsculas). Solo activo para eventos de mensajes.
ÁmbitoGlobal, servidor, canal o usuario
ValorNombre del servidor / canal / usuario (dejar vacío para Global)
AcciónTTS + sonido, solo TTS, solo sonido, o silencio (suprime todo)

Ejemplos

  • Suprimir todos los mensajes de chat excepto en el canal "Lounge": regla global "Chat → Silencio", luego una regla más específica "Chat, Canal: Lounge → TTS + sonido".
  • TTS solo cuando aparece la palabra clave "importante": regla "Chat, Palabra clave: importante → TTS". Sin la palabra clave en el mensaje no se activa ningún TTS.
  • Leer siempre los mensajes privados del usuario "Max": regla "Mensaje privado, Usuario: Max → TTS + sonido".

Orden y prioridad

Las reglas se recorren de arriba a abajo. Gana la primera regla coincidente. Por tanto, las reglas más específicas (usuario antes que canal, antes que servidor, antes que global) deben colocarse más arriba. Use "Subir"/"Bajar" para ajustar el orden.

11 · Configuración de audio

Activar el micrófono

12 · Procesamiento del micrófono

El área "Procesamiento del micrófono" se encuentra en la pestaña Audio y ofrece procesamiento de señal avanzado para la señal de su micrófono antes de que se transmita.

Modos de procesamiento

ModoDescripciónRecomendación
NingunoSin procesamiento adicionalSi el micrófono ya ofrece buena calidad
Noise GateCorta todo lo que está por debajo del umbral – sin ruido de fondo cuando no hablaEntorno ruidoso
ExpanderAumenta el contraste entre la señal fuerte y el ruidoMicrófono débil con ruido de fondo
LimiterLimita los picos para evitar la saturaciónSi a veces habla muy alto
Expander+LimiterCombina Expander y LimiterRecomendación general para entornos irregulares

Parámetros

ParámetroDescripción
Umbral (dB)Nivel por debajo (Gate/Expander) o por encima (Limiter) del cual interviene el modo
Supresión de ruido (dB)Intensidad de la atenuación por debajo del umbral (para Noise Gate y Expander)

Vista previa del micrófono

El botón Iniciar/Detener vista previa le permite escucharse a sí mismo mediante bucle, sin estar conectado a un servidor. Así puede probar directamente los ajustes de procesamiento.

Use la vista previa junto con el vúmetro de la barra de acciones rápidas para encontrar el ajuste de umbral óptimo.
Todos los ajustes de procesamiento se guardan en el perfil de audio y se restauran al cargar un perfil.

13 · TTS del sistema (espeak-ng)

Accesible mediante: Configuración → Sistema y TTS

La función de TTS integrada (espeak-ng) lee automáticamente los mensajes del sistema, el chat y los mensajes privados.

Activar/desactivar TTS

  • TTS activo (Alt+T): activa la salida de voz.
  • Nuevo mensaje interrumpe (Alt+N): interrumpe un anuncio en curso cuando llega uno nuevo.

¿Qué se debe leer en voz alta?

OpciónAtajo AltDescripción

Configurar la voz

  1. Activar TTS activo.
  2. Elegir un idioma en el menú desplegable (p. ej. "es" para español, "Todos" para todos los idiomas).
  3. Opcional: introducir un filtro para buscar en la lista de voces.

Parte E · Medios y archivos

15 · Grabación y transmisión de medios

Accesible mediante: menú desplegable de área → "Grabación y Medios"

Grabar el canal

  1. Seleccionar el formato de grabación (WAV, MP3 16k–320k).
  2. Hacer clic en Iniciar grabación (Alt+A) y elegir una ubicación de guardado.
  3. Hacer clic en Detener grabación (Alt+S) al terminar.

Grabar conversaciones automáticamente

Si está activado, cada usuario que hable se graba por separado:

  1. Marcar "Grabación automática" (Alt+M).
  2. Elegir una carpeta de destino.
  3. Definir el patrón de nombre de archivo (marcadores: %Y%m%d-%H%M%S, #userid#, %username%).
  4. Elegir el formato e "Incluir voz propia" (Alt+E) según sea necesario.
  5. Hacer clic en Aplicar (Alt+W).

Fuentes de transmisión

Seleccione la fuente en el menú desplegable "Fuente de transmisión":

Archivo

  1. Introducir la ruta del archivo multimedia o hacer clic en Examinar (Alt+D).
  2. Formatos compatibles: WAV, MP3, OGG, Opus, MP4, AVI, MKV.
  3. Reproducir (Alt+A) – transmite el archivo al canal actual.
  4. Posición (0–1000): campo numérico para saltar dentro del archivo.
  5. Volumen de transmisión (25–400): 100 = normal, 200 = doble volumen.

YouTube, SoundCloud, Twitch, Bandcamp, Vimeo, Mixcloud (mediante yt-dlp)

  1. Para YouTube/SoundCloud: introducir un término de búsqueda y hacer clic en Buscar (Alt+S).
  2. Seleccionar un resultado de la lista – el enlace se introduce automáticamente.
  3. O pegar directamente un enlace.
  4. Hacer clic en Transmitir (Alt+R).
yt-dlp debe estar instalado o incluido en el paquete de la aplicación. Para Twitch, Bandcamp, Vimeo, Mixcloud: pegar el enlace directamente.

Radio web

  1. Elegir una emisora de la lista predefinida, o buscar emisoras (Alt+S).
  2. La URL de la transmisión también se puede introducir manualmente.
  3. Hacer clic en Transmitir radio web (Alt+W).

Podcasts

  1. Buscar el nombre de un podcast (Alt+S) o introducir directamente la URL del feed.
  2. Cargar el feed (Alt+F).
  3. Seleccionar un episodio de la lista y hacer clic en Transmitir episodio (Alt+E).

Lista de reproducción

  1. Añadir archivos a la lista de reproducción mediante Añadir… (Alt+H) o Cargar M3U… (Alt+M).
  2. Ajustar el orden con "Subir" / "Bajar".
  3. Reproducir comienza desde la pista seleccionada; con "Avanzar automáticamente" la lista se reproduce por completo.
  4. Exportar la lista de reproducción como M3U o eliminar pistas individuales.

Spotify NUEVO

Requiere Spotify Premium y el binario librespot incluido.
  1. En el primer inicio, hacer clic en Iniciar sesión con Spotify… — el navegador se abre automáticamente.
  2. Iniciar sesión con la cuenta de Spotify en el navegador; la página confirma el éxito.
  3. Personalizar el nombre del dispositivo si lo desea (por defecto: "TeamTalk Stream").
  4. Elegir la calidad (320 / 160 / 96 kbps).
  5. Hacer clic en Iniciar Spotify.
  6. En la aplicación de Spotify (móvil, escritorio o web), tocar el icono del altavoz y seleccionar el nombre del dispositivo.
  7. Controlar la música en la aplicación de Spotify — el audio se transmite en directo al canal.

Después del primer inicio de sesión, las credenciales se guardan localmente; no es necesario volver a iniciar sesión en inicios posteriores. Mediante Cerrar sesión se eliminan los datos guardados.

Si falta librespot: ejecutar python scripts/download_librespot.py en el directorio del proyecto (requiere Rust / Cargo).

Deezer NUEVO

Se requiere token ARL. Deezer ha deshabilitado el inicio de sesión con usuario/contraseña para aplicaciones de terceros.

Cómo obtener el token ARL:

  1. Iniciar sesión en deezer.com en el navegador.
  2. Abrir las herramientas de desarrollo (F12) → Application (Chrome) o Almacenamiento (Firefox) → Cookies → deezer.com.
  3. Copiar el valor de la cookie arl (192 caracteres).

Usar el token en el cliente:

  1. Pegar el token ARL en el campo "Token ARL" y hacer clic en Guardar token (una sola vez, se guarda localmente).
  2. Introducir un término de búsqueda y hacer clic en Buscar — la búsqueda pública de Deezer no requiere cuenta.
  3. Seleccionar una pista de la lista de resultados y hacer clic en Transmitir.
  4. La pista se descarga y se transmite automáticamente al canal.

El token ARL caduca cada 3–6 meses. Si aparece un error, simplemente copie uno nuevo desde el navegador.

Parte H · Referencia

21 · Diferencias entre plataformas

macOS

  • Navegación con VoiceOver: VO+flechas se mueve por todos los elementos. VO+Espacio activa. VO+M para la barra de menús.
  • Listas: se anuncian como "Lista, N elementos" (parche de VoiceOver activo). Las flechas arriba/abajo navegan.
  • Menús desplegables: se anuncian como "botón emergente". Las flechas cambian el valor.
  • Campos numéricos (SpinCtrl): las flechas cambian el valor; es posible la entrada directa.
  • Atajos de foco: Cmd+1–4 mueven el foco a la lista de canales, historial de chat, entrada, registro.
  • Cerrar la ventana: Cmd+W minimiza a la bandeja. Cmd+Q cierra por completo.
  • Atajos estándar: Cmd+O (abrir archivo), Cmd+N (nuevo cliente), Cmd+, (configuración).
  • Permiso de micrófono: macOS solicita acceso al micrófono una vez. Concédalo en Configuración del sistema → Privacidad.
  • Línea braille: todos los nombres y roles de los controles se nombran en el idioma de interfaz elegido.
  • Notificaciones: notificaciones nativas de macOS para eventos de canal (filtrado por canal desde la v6.1.6).

Windows

  • Navegación con NVDA/JAWS: Tab/Mayús+Tab navega, Intro/Espacio activa. En modo formulario, las flechas navegan dentro de las listas.
  • Atajos de teclado: Alt+letra subrayada activa botones/casillas. Todos los botones tienen atajos únicos por área.
  • Navegación por menús: Alt abre la barra de menús, luego las letras.
  • Atajos estándar: Ctrl+O, Ctrl+N, F4 (configuración).
  • Bandeja: doble clic en el icono de bandeja vuelve a abrir la ventana. Clic derecho abre el menú de la bandeja.
  • Windows Defender: puede que sea necesario añadir una excepción en el primer inicio.

Linux

  • Navegación con Orca: similar a Windows. Insertar+Tab para la lista de elementos.
  • Dispositivos de audio: PulseAudio o ALSA. Elegir el nombre del dispositivo en el menú desplegable.
  • espeak-ng: se prefiere la versión del sistema (sudo apt install espeak-ng).
  • Bandeja: funciona con entornos de escritorio compatibles (GNOME con extensión AppIndicator, KDE).
  • Limitaciones: el uso compartido de escritorio y el control remoto del ratón pueden estar limitados según el compositor.
