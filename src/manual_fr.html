1 · À propos de cette application & Nouveautés

Le TeamTalk VoiceOver Client est un client graphique pour le protocole TeamTalk, conçu spécifiquement pour les utilisateurs aveugles et malvoyants. Tous les contrôles sont optimisés pour les lecteurs d'écran :

  • macOS – VoiceOver avec support de plage braille (plateforme principale)
  • Windows – NVDA, JAWS (entièrement pris en charge, raccourcis Alt+lettre pour tous les boutons)
  • Linux – Orca (prise en charge de base)

TeamTalk est un service de communication vocale similaire à Mumble ou Discord. Le client se connecte à un serveur TeamTalk, rejoint des canaux et permet la communication vocale et écrite.

L'application prend en charge quatre langues d'interface : allemand, anglais, français, espagnol. La langue peut être modifiée dans Paramètres → Général → Langue de l'application ; l'application redémarre ensuite.

3 · Installation & premier démarrage

macOS

  1. Ouvrir le fichier DMG (double-clic).
  2. Faire glisser « TeamTalk VO Client.app » dans le dossier Applications.
  3. Au premier démarrage : clic droit → « Ouvrir » (une seule fois, à cause de l'avertissement Gatekeeper).
  4. Accorder l'autorisation du microphone et, le cas échéant, de l'enregistrement d'écran si demandé.

Windows

  1. Télécharger le fichier EXE ou ZIP.
  2. Extraire le contenu du ZIP dans un dossier (par ex. C:\Programmes\TeamTalk VO Client).
  3. Démarrer TeamTalk VO Client.exe.
  4. Windows Defender / SmartScreen : choisir « Exécuter quand même ».

Linux

  1. Télécharger et extraire l'AppImage ou le tar.gz.
  2. Rendre l'AppImage exécutable : chmod +x TeamTalk*.AppImage
  3. Démarrer : ./TeamTalk*.AppImage
  4. Installer espeak-ng si ce n'est pas déjà fait : sudo apt install espeak-ng

Premier démarrage

Au premier démarrage, la fenêtre principale s'ouvre. Pour vous connecter, ouvrez d'abord la fenêtre de connexion via Fichier → Connecter ou le bouton Connecter dans la barre d'actions rapides. Les connexions serveur sont enregistrées comme profils et restaurées à chaque démarrage.

Mise à jour de l'application

Via Aide → Rechercher des mises à jour, l'application vérifie si une nouvelle version est disponible. Le DMG de mise à jour (macOS) est téléchargé et enregistré directement dans l'application – aucun accès navigateur au dépôt n'est nécessaire.

9 · Canaux, liste des utilisateurs & chat

Ceci est la zone principale « Canaux et Chat ». Elle est divisée en deux moitiés :

Moitié gauche : canaux & utilisateurs

  • Liste des canaux : affiche tous les canaux du serveur. Format : Nom du canal, Utilisateurs : N, Mot de passe : Oui/Non. Double-clic ou Entrée rejoint le canal. Les mots de passe de canal sont demandés si nécessaire.
  • Liste des utilisateurs : affiche tous les utilisateurs du canal actuel. Format : Pseudo, Nom d'utilisateur, Statut. Le double-clic ouvre le chat privé avec cet utilisateur.

Le bouton Rejoindre le canal (Alt+K) rejoint le canal sélectionné.

Moitié droite : chat

  • Historique du chat : champ de texte multi-lignes avec les messages de canal et privés.
  • Champ de saisie : taper un message, puis Entrée ou « Envoyer » (Alt+S).
  • Case à cocher Privé (Alt+P) : envoyer le message comme message privé à l'utilisateur sélectionné.
  • Exporter l'historique (Alt+E) : enregistre l'historique du chat au format TXT.
  • Effacer l'historique (Alt+L) : supprime l'historique affiché après confirmation. Si l'enregistrement de l'historique est actif, le fichier enregistré est également supprimé.

Enregistrement de l'historique du chat (en option)

Si l'option est activée dans Paramètres → Général → Enregistrer l'historique du chat, les messages sont enregistrés par serveur dans un fichier JSON (max. 200 entrées). L'historique est automatiquement chargé à la prochaine connexion au même serveur.

L'historique peut être réinitialisé à tout moment via « Effacer l'historique ».

10 · Notifications

macOS – Notifications natives

Les notifications système macOS pour les événements de canal n'apparaissent que lorsque l'utilisateur concerné est dans le même canal que vous. Cela réduit les notifications non pertinentes sur les serveurs très fréquentés.

Les notifications peuvent être activées et désactivées de manière centralisée via Paramètres → Affichage → Activer les notifications.

ÉvénementNotification (exemple)
Un utilisateur rejoint votre canal« Florian a rejoint – canal Lounge »
Un utilisateur quitte votre canal« Florian a quitté – canal Lounge »
Nouveau message privéNom de l'expéditeur + aperçu du message
Pour désactiver les notifications : désactivez Paramètres → Affichage → Activer les notifications. Vous pouvez aussi les désactiver globalement dans Réglages système → Notifications → TeamTalk VO Client.

Événements sonores

En plus des notifications natives, un son personnalisé peut être joué pour chaque événement. La configuration se fait sous Paramètres → Événements sonores (→ Section 18).

Règles de notification NOUVEAU depuis v7.1

Via Paramètres → Règles de notification…, vous contrôlez finement quels événements déclenchent la synthèse vocale, un son, les deux ou rien. Les règles s'appliquent du spécifique au général : une règle utilisateur l'emporte sur une règle de canal, qui l'emporte sur une règle de serveur, qui l'emporte sur une règle globale.

Champs d'une règle

ChampDescription
ÉvénementQuel événement cette règle concerne : tous, utilisateur rejoint/quitte le canal, chat de canal, message privé, etc.
Mot-clé NOUVEAU v7.4Facultatif : la règle ne s'applique que si le message contient ce mot (insensible à la casse). Actif uniquement pour les événements de message.
PortéeGlobal, serveur, canal ou utilisateur
ValeurNom du serveur / canal / utilisateur (laisser vide pour Global)
ActionTTS + son, TTS seul, son seul, ou muet (tout supprimer)

Exemples

  • Supprimer tous les messages de chat sauf dans le canal « Lounge » : règle globale « Chat → Muet », puis règle plus spécifique « Chat, Canal : Lounge → TTS + son ».
  • TTS seulement si le mot-clé « important » apparaît : règle « Chat, Mot-clé : important → TTS ». Aucune TTS n'est déclenchée sans le mot-clé dans le message.
  • Toujours lire les messages privés de l'utilisateur « Max » : règle « Message privé, Utilisateur : Max → TTS + son ».

Ordre et priorité

Les règles sont parcourues de haut en bas. La première règle correspondante l'emporte. Les règles plus spécifiques (utilisateur avant canal avant serveur avant global) doivent donc être placées plus haut. Utilisez « Monter »/« Descendre » pour ajuster l'ordre.

13 · Synthèse vocale système (espeak-ng)

Accessible via : Paramètres → Système & TTS

Activer/désactiver la synthèse vocale

  • TTS actif (Alt+T) : active la sortie vocale.
  • Nouveau message interrompt (Alt+N) : interrompt l'annonce en cours quand une nouvelle arrive.

Que faut-il lire à voix haute ?

15 · Enregistrement et streaming média

Accessible via : liste déroulante de zone → « Enregistrement et Médias »

Enregistrer le canal

  1. Sélectionner le format d'enregistrement (WAV, MP3 16k–320k).
  2. Cliquer sur Démarrer l'enregistrement (Alt+A) et choisir un emplacement.
  3. Cliquer sur Arrêter l'enregistrement (Alt+S) une fois terminé.

Enregistrer automatiquement les conversations

Si activé, chaque utilisateur qui parle est enregistré séparément :

  1. Cocher « Enregistrement automatique » (Alt+M).
  2. Choisir un dossier cible.
  3. Définir le modèle de nom de fichier (variables : %Y%m%d-%H%M%S, #userid#, %username%).
  4. Choisir le format et « Inclure sa propre voix » (Alt+E) au besoin.
  5. Cliquer sur Appliquer (Alt+W).

Sources de streaming

Choisissez la source dans la liste déroulante « Source de streaming » :

Fichier

  1. Saisir le chemin du fichier média ou cliquer sur Parcourir (Alt+D).
  2. Formats pris en charge : WAV, MP3, OGG, Opus, MP4, AVI, MKV.
  3. Lire (Alt+A) – diffuse le fichier dans le canal actuel.
  4. Position (0–1000) : champ numérique pour se déplacer dans le fichier.
  5. Volume de streaming (25–400) : 100 = normal, 200 = double volume.

YouTube, SoundCloud, Twitch, Bandcamp, Vimeo, Mixcloud (via yt-dlp)

  1. Pour YouTube/SoundCloud : saisir un terme de recherche et cliquer sur Rechercher (Alt+S).
  2. Sélectionner un résultat dans la liste – le lien est saisi automatiquement.
  3. Ou coller directement un lien.
  4. Cliquer sur Diffuser (Alt+R).
yt-dlp doit être installé ou inclus dans le bundle de l'application. Pour Twitch, Bandcamp, Vimeo, Mixcloud : coller le lien directement.

Radio web

  1. Choisir une station dans la liste prédéfinie, ou rechercher des stations (Alt+S).
  2. L'URL du flux peut également être saisie manuellement.
  3. Cliquer sur Diffuser la radio web (Alt+W).

Podcasts

  1. Rechercher le nom d'un podcast (Alt+S) ou saisir directement l'URL du flux.
  2. Charger le flux (Alt+F).
  3. Sélectionner un épisode dans la liste et cliquer sur Diffuser l'épisode (Alt+E).

Playlist

  1. Ajouter des fichiers à la playlist via Ajouter… (Alt+H) ou Charger M3U… (Alt+M).
  2. Ajuster l'ordre avec « Monter » / « Descendre ».
  3. Lire démarre à partir du titre sélectionné ; avec « Avancer automatiquement », la playlist se déroule en continu.
  4. Exporter la playlist en M3U ou supprimer certains titres.

Spotify NOUVEAU

Nécessite Spotify Premium et le binaire librespot fourni.
  1. Au premier démarrage, cliquer sur Se connecter avec Spotify… — le navigateur s'ouvre automatiquement.
  2. Se connecter avec le compte Spotify dans le navigateur ; la page confirme le succès.
  3. Personnaliser le nom de l'appareil selon vos souhaits (par défaut : « TeamTalk Stream »).
  4. Choisir la qualité (320 / 160 / 96 kbps).
  5. Cliquer sur Démarrer Spotify.
  6. Dans l'application Spotify (téléphone, ordinateur ou web), toucher l'icône du haut-parleur et sélectionner le nom de l'appareil.
  7. Contrôler la musique dans l'application Spotify — le son est diffusé en direct dans le canal.

Après la première connexion, les identifiants sont enregistrés localement ; aucune nouvelle connexion n'est nécessaire au prochain démarrage. Via Se déconnecter, les données enregistrées sont supprimées.

Si librespot est manquant : exécuter python scripts/download_librespot.py dans le répertoire du projet (nécessite Rust / Cargo).

Deezer NOUVEAU

Jeton ARL requis. Deezer a désactivé la connexion par identifiant/mot de passe pour les applications tierces.

Comment obtenir le jeton ARL :

  1. Se connecter sur deezer.com dans le navigateur.
  2. Ouvrir les outils de développement (F12) → Application (Chrome) ou Stockage (Firefox) → Cookies → deezer.com.
  3. Copier la valeur du cookie arl (192 caractères).

Utiliser le jeton dans le client :

  1. Coller le jeton ARL dans le champ « Jeton ARL » et cliquer sur Enregistrer le jeton (une seule fois, enregistré localement).
  2. Saisir un terme de recherche et cliquer sur Rechercher — la recherche publique Deezer ne nécessite pas de compte.
  3. Sélectionner un titre dans la liste des résultats et cliquer sur Diffuser.
  4. Le titre est téléchargé et automatiquement diffusé dans le canal.

Le jeton ARL expire tous les 3 à 6 mois. En cas d'erreur, il suffit d'en copier un nouveau depuis le navigateur.

Partie H · Référence

21 · Différences entre plateformes

macOS

  • Navigation VoiceOver : VO+flèches se déplacent parmi tous les éléments. VO+Espace active. VO+M pour la barre de menus.
  • Listes : annoncées comme « Liste, N éléments » (correctif VoiceOver actif). Les flèches haut/bas permettent de naviguer.
  • Listes déroulantes : annoncées comme « bouton menu ». Les flèches modifient la valeur.
  • Champs numériques (SpinCtrl) : les flèches modifient la valeur ; saisie directe possible.
  • Raccourcis de focus : Cmd+1–4 déplacent le focus vers la liste des canaux, l'historique du chat, la saisie, le journal.
  • Fermer la fenêtre : Cmd+W réduit dans la barre d'état. Cmd+Q quitte complètement.
  • Raccourcis standard : Cmd+O (ouvrir un fichier), Cmd+N (nouveau client), Cmd+, (paramètres).
  • Autorisation du microphone : macOS demande une fois l'accès au microphone. À accorder dans Réglages système → Confidentialité.
  • Plage braille : tous les noms et rôles des contrôles sont nommés dans la langue d'interface choisie.
  • Notifications : notifications macOS natives pour les événements de canal (filtrage par canal depuis la v6.1.6).

Windows

  • Navigation NVDA/JAWS : Tab/Maj+Tab navigue, Entrée/Espace active. En mode formulaire, les flèches naviguent dans les listes.
  • Raccourcis clavier : Alt+lettre soulignée active les boutons/cases à cocher. Tous les boutons ont des raccourcis uniques par zone.
  • Navigation dans les menus : Alt ouvre la barre de menus, puis les lettres.
  • Raccourcis standard : Ctrl+O, Ctrl+N, F4 (paramètres).
  • Barre d'état : double-clic sur l'icône de la barre d'état pour rouvrir la fenêtre. Clic droit ouvre le menu de la barre d'état.
  • Windows Defender : ajouter éventuellement une exception au premier démarrage.

Linux

  • Navigation Orca : similaire à Windows. Insertion+Tab pour la liste des éléments.
  • Périphériques audio : PulseAudio ou ALSA. Choisir le nom du périphérique dans la liste déroulante.
  • espeak-ng : la version système est préférée (sudo apt install espeak-ng).
  • Barre d'état : fonctionne avec les environnements de bureau compatibles (GNOME avec extension AppIndicator, KDE).
  • Limitations : le partage d'écran et le contrôle à distance de la souris peuvent être limités selon le compositeur.
